## 二、 100% 严谨的文物历史考据（严格依据现场展牌）

游戏中出现的所有文物信息、UI 图鉴与 NPC 台词必须严格遵循以下现场实拍考据，确保“文化准确性”拿满分：

- **标准名称**：驯马场面铜贮贝器（Bronze Cowrie Container Depicting Horse Taming Scene）
- **年代**：西汉（公元前 202 — 公元 8 年）
- **出土地点**：云南江川李家山墓地出土
- **馆藏单位**：云南李家山青铜器博物馆藏（现于东莞市博物馆特展展出）
- **核心器物结构与微缩景观（“八组 · 十人七马 · 双虎耳”）**：
  1. **器物功能**：贮贝器是滇文化的独有器物，用于贮藏作为货币的**海贝**（即便当时中原已是西汉、通行铜钱，古滇国贵族依然视海贝为最高硬通货与权力象征）。此器真实表现了滇人集体驯马的场景，似为供奉驯化和驾驭烈马、蛮牛的**“御神”**。
  2. **器盖中央（核心三人组）**：
     - **铜鼓主尊（御神/马场大主）**：一男子坐于中央**铜鼓**之上，双脚踏地，着长衣、长裤，**耳佩环，腕戴宽边玉镯，左腰佩剑**，左手扶膝，**右手前伸作训斥状**。
     - **持伞侍从（背后一人）**：立于主尊身后，双手持长柄大伞为主尊遮阳/彰示威仪。
     - **受斥跪者（身前一人）**：位于主尊正前方，**右膝跪地，双手平伸似作接受斥责状**。
  3. **器盖周沿（外围七组“一人牵一马”）**：
     - 其余七组为**一人牵一马**环绕器盖周沿分布，作牵马行走、驯服烈马状。
  4. **人物共同特征**：盖上十人皆**头顶梳螺髻，头缠帕，腰束带，跣足（赤脚）**。
  5. **器身特征**：器身呈束腰圆筒状，两侧攀附一对威猛的立体**虎形耳**（双虎昂首扒住器壁），器表带有千年青铜绿锈与修复裂痕。
  6. **展厅空间联动（根据现场实拍照片第3、4张）**：展柜正后方的巨幅背景墙与邻近展位正是带有干栏式建筑顶棚的**《纺织场面铜贮贝器》**（纺织女工与纺织厂主），同展厅还有**《三星堆祭司青铜头像》**。

## 三、 游戏核心世界观与剧情设定：《器盖上的复活夜》

### 1. 一句话故事梗概（Logline）

子夜钟声敲响，东莞市博物馆展厅陷入沉睡。西汉《驯马场面铜贮贝器》腹腔内珍藏千年的“御神海贝”离奇失踪！器盖上定格了两千年的**“十人七马”青铜微缩雕像**在月光下集体复活。玩家将化身“博物馆守夜人/文物唤醒师”，用手柄转动青铜器盖，盘问端坐铜鼓的佩剑主尊、右膝跪地的受斥马夫、持伞侍从与外围牵马人，甚至联动隔壁《纺织贮贝器》的织女，在天亮前揭开西汉滇国马场主人的千年秘密！

### 2. 核心悬念与真相设计（三幕剧结构）

- **表面冲突（第一幕：器盖惊变）**：
  玩家发现器盖中央的【佩剑主尊】正伸出右手严厉训斥【右膝跪地的马夫阿滇】，指控他在今夜驯服七匹烈马时惊扰了器身两侧的【护宝双虎】，导致贮贝器内部的海贝被盗。
- **深入调查（第二幕：十人七马的罗生门）**：
  玩家通过手柄摇杆在器盖圆盘上旋转聚焦，逐一盘问 5 个核心青铜 Agent 角色，并切换到【文物微观勘验模式】观察现场实拍图细节：
  - 发现细节1：所有驯马人皆**“跣足（赤脚）”**且腰间束带紧绷，根本无法藏匿大量海贝。
  - 发现细节2：受斥者虽然**右膝跪地、双手平伸**，但他摊开的双手空空如也，眼神看向器盖边缘的**第 7 匹受惊烈马**和展柜后方的**《纺织场面铜贮贝器》**。
  - 发现细节3：持伞侍从透露，主尊虽坐于**铜鼓**之上、腕戴**宽边玉镯**、左腰**佩剑**，但近年来西汉中原商道开通，汉朝铜钱（半两/五铢）冲击滇国市场，马场主尊正在暗中跟隔壁“纺织厂老板”做一笔大交易。
- **终极真相（第三幕：御神之祭与跨时空共鸣）**：
  海贝并非被盗！而是【佩剑主尊】为了向统御烈马与蛮牛的**“御神”**祈求马场兴旺、并与隔壁【纺织贮贝器】的主人置换蜀锦与丝绸，亲自将海贝封入器底暗格作为陪葬永存。而跪地马夫之所以受斥，是因为他不忍心让自己亲手驯化的“第七匹汗血滇马”随葬，试图在铸造定格前的最后一刻解开缰绳放走烈马！
  - **升华结局**：玩家解开真相后，帮助跪地马夫与佩剑主尊达成千年和解，点亮“十人七马”全部图鉴知识点，器盖化作璀璨的金色星盘，完美呼应“让观众在观察和探索中理解文物”的命题要求。

## 七、 完整游戏流程（控制在 2.5 分钟内通关，完美契合 3 分钟录屏！）

为了让你现场演示和录制 3 分钟以内的 16:9 参赛视频节奏拉满，游戏设计为紧凑的 **4 步闭环（约 2~2.5 分钟体验时长）**：

- **Step 1：叩鼓唤醒（0:00 - 0:25）**
  - 开场展示《驯马场面铜贮贝器》威严的青铜立面，按下手柄 **`Y 键（叩击中央铜鼓）`**，伴随浑厚的西汉铜鼓声波特效，器盖上的“十人七马”被金色灵光唤醒。
- **Step 2：三方对峙与细节勘验（0:25 - 1:30）**
  - 摇杆选中中央【佩剑主尊】与【右膝跪地者】，触发“训斥与失贝”悬案。
  - 按下 **`X 键`** 打开现场实拍展牌与器物特写，采集 3 个关键文物铁证：
    1. **【铁证一：十人皆跣足（赤脚）且束腰带】**（证明驯马人身上无法私藏海贝）；
    2. **【铁证二：主尊耳佩环、腕戴宽边玉镯、左腰佩剑、坐于铜鼓】**（揭示墓主人极高的贵族与马场大老板身份）；
    3. **【铁证三：器盖外围七组“一人牵一马”与“御神”信仰】**（揭示此器并非普通存钱罐，而是供奉驾驭烈马、蛮牛之“御神”的礼器）。

## 九、 v2.0 优化需求（2026-10-24 追加）

### 1. 启动动画迁移：流金绘影 · 青铜线稿

- 迁移自 `03travel-gallery` 的 BootAnimation 渲染管线（纯前端、无动画库）：
  1. 离屏 Canvas 对器物实拍图做亮度梯度边缘扫描，生成鎏金/青铜绿锈线稿；
  2. 约 110 根发丝级锥形渐变流光丝线（纯函数解析曲线 + 每帧全清屏 + source-over），从屏幕两侧飞向器物轮廓靶点；
  3. 金线显影 → 高清实拍晕染浮现 → 交叉溶解进标题画面；全程约 4 秒，任意键/点击可跳过。
- **兼容性硬性约束**：`file://` 双击打开时 Canvas `getImageData` 读取本地图片会触发浏览器安全拦截，因此线稿提取必须使用内嵌的 base64 低清缩略图（同源 data URI），高清图仅作显示层。

### 2. 姓名登录 + 本地数据库（多人 demo）

- 不引入后端：localStorage 作为本地数据库（表 `gm_db_v1.players`）：`姓名 → { 游玩次数, 最高分, 最快通关, 最近游玩时间 }`。
- 标题画面输入姓名进入（默认「守夜人」），老玩家以名字芯片一键登录；HUD 新增 🏆 排行榜弹窗（按最高分排序）。

### 3. 一分钟速通 + 快速奖励反馈

- 通关门槛压缩：文物细节 6→3、海贝线索 4→2、双虎问答 3 题→2 题；打字机速度加倍。
- 新增计分系统：细节/线索 +100（即时金色飘分动画）、问答通过 +150、揭晓真相 +300、60 秒内通关按剩余时间追加速通奖励。
- HUD 新增 ⏱ 计时器与 ✦ 分数槽；结案报告显示姓名/用时/得分/本机排名。

### 4. API 真实感（可选，离线兜底）

- 设置面板新增「成绩同步 API」（endpoint + token）：通关时 POST 成绩、排行榜尝试 GET 远程榜单，任何失败静默回退本地数据，断网零报错。
