# 《器盖上的复活夜：古滇万贝迷踪》产品规范

## 1. 产品定位

以“驯马场面铜贮贝器”为核心文化原型的 60 秒离线街机游戏。玩家扮演闭馆后的守器人，通过旋转器盖与敲响铜鼓，追回七匹铜马带走的海贝。

产品目标：一分钟内上手、单一动作贯穿全局、强反馈、可重复挑战，并让玩法与器物结构形成明确联系。设备覆盖展厅电脑（键盘 / 鼠标 / 手柄）与手机、平板、触屏电脑。

## 2. 核心叙事

1. 博物馆闭馆后，器盖上的人马苏醒。
2. 七匹铜马携带海贝沿器盖逃窜。
3. 玩家旋转器盖、敲响中央铜鼓，追回海贝。
4. 御神主尊发出雷霆训斥，玩家敲鼓御守。
5. 黎明前双虎攀器夺贝，玩家连续敲鼓将其震落。
6. 晨光照入展厅，一切重新凝固，成绩写入万贝守器榜。

## 3. 用户流程

```text
四幕故事与计分说明
  → 登录 / 注册 / 游客试玩（本机名册可一键进入）
  → 操控方式：键盘 / 手柄 / 鼠标 / 触屏
  → 点按手感：点马即敲 / 两步操作 / 滑动旋盖（仅鼠标与触屏）
  → 首次登录询问是否进入新手教程（只问一次）
  → 四档难度
  → 两键说明
  → 三秒倒数
  → 60 秒游戏
  → 结算、四端榜单、文物考据
```

“记住我”默认开启：本机再次打开会跳过剧情与登录，直接进入操控方式选择。

## 4. 账号规范

- 账号由 **游戏名（唯一）+ 邮箱（选填、唯一）+ 口令** 组成，另存教程状态与四端最高分。
- 登录支持游戏名或邮箱；口令最少 6 位。
- 旧版本只登记姓名，升级后自动把历史姓名转为账号，**初始口令为 `12345678`**，并在登录页提示。
- 本机名册以胶囊形式列出已有账号，点选即登录（仍为初始口令的账号直接进入，改过口令的需要补输）。
- 支持游客试玩：可完整游玩，但成绩不进入榜单。
- 账号面板提供：四端最高分、手感切换、修改口令、退出登录、删除本机账号。
- 所有数据只保存在当前浏览器，不上传、不联网、不跨设备同步。

## 5. 操作规范

### 键盘模式

- `←` / `→`：旋转器盖、选择目标。
- `空格`：敲鼓；用于封印铜马、抵御训斥、击退双虎。
- `Enter`：确认与开始。
- `Esc`：返回上一层。

### 手柄模式

- `A` 或 `Start`：推进剧情、名册登录、确认与开始。
- 左摇杆：按 360° 方向自动吸附到最近的铜马槽位，箭头不得停在两个槽位之间。
- 十字键：逐个切换铜马槽位。
- `A`：敲鼓；用于全部核心动作。
- `Y`：结算画面至少展示 5 秒后开启下一局。
- `B`：返回上一层。

### 鼠标模式

- 指针移到铜马、点击即旋盖并敲鼓。
- 点击器盖任意处或中央铜鼓同样敲鼓，不额外显示按钮。

### 触屏模式

三种手感，随时可在账号面板切换：

| 手感     | 交互                            | 适合         |
| -------- | ------------------------------- | ------------ |
| 点马即敲 | 点发光的铜马＝对准＋敲鼓        | 最快，小朋友 |
| 两步操作 | 点铜马只旋盖，点铜鼓 / 大鼓才敲 | 接近键盘手感 |
| 滑动旋盖 | 拖动器盖连续旋转，点铜鼓敲      | 最像亲手转盖 |

- 主尊训斥与双虎阶段忽略手感差异：任何点按都算敲鼓。
- 右下角「敲鼓」大按钮只属于触屏：两步与滑动手感常驻，点马即敲手感仅在连打时出现；鼠标与手柄不显示。
- 竖屏设备显示“请把设备横过来”，可手动选择继续竖屏。
- 铜马有 1.68 倍隐形点击热区，保证手指点得中。
- 鼠标指针在所有界面可见，进入鼠标模式后赛场显示瞄准光标、铜马显示手型光标。

## 6. 一局节奏

- 60～50 秒：七马携贝苏醒，目标停留 3.6 秒。
- 50～40 秒：完成热身，目标停留 3.0 秒。
- 40～20 秒：午夜迷踪，目标停留 2.7 秒。
- 20～0 秒：双虎攀器，目标停留 2.5 秒并增强整体反馈。
- 每 12 秒触发一次主尊训斥。
- 剩余 20 秒时触发一次 3 秒双虎连打。

游戏时间以真实时间计算，事件不会延长一局的 60 秒上限。

### 四档难度

- 亲子启蒙：目标 4.8～5.8 秒，训斥在 22 秒和 44 秒出现，连打 6 次即可御守，失误不扣贝。
- 守器初醒：当前标准规则，作为中间难度。
- 万贝狂潮：当前高难规则，保留更快目标、五次训斥与高倍率奖励。
- 极速试炼：无需解锁的极速关卡，目标刷新更快，专注考验抓马反应速度。
- 账号四端最高分中的最大值达到 `30,000` 贝后解锁「万贝狂潮」。

#### 极速猎贝计分

每次铜马成功锁定都会根据从亮起到按键的反应时间计算速度倍率：`<0.45s ×2.2`、`<0.9s ×1.7`、`<1.5s ×1.3`、其余 `×1.0`，结算提示会显示“闪电/疾驰/迅捷/稳健锁马”。

## 7. 铜马的视觉规则

- 铜马是内联 SVG 剪影，不再是文字圆点。
- 每匹铜马按所在槽位的角度朝外站立，目标亮起时会向器盖外沿冲刺，四腿奔跑。
- 从器盖中心到铜马的缰绳（虚线）在目标亮起时绷紧变红；马圈由虚线转为赤红实线并脉动，形成“警戒”状态。
- 载贝御马（×2）使用金色高亮与“御马 ×2”标签。
- 编号固定在马位左上角，按键提示固定在马位下缘，二者都不随马身旋转。

## 8. 计分规则

- 普通封印：基础 `+300` 海贝。
- 0.38 秒内完成：基础奖励提高为 `+500` 海贝。
- 连击达到阈值：自动双倍。
- 铜鼓灵力达到 100%：自动进入 5 秒三倍“万贝归潮”。
- 主尊御守成功：`+800` 海贝。
- 双虎阶段每次有效敲鼓：`+100` 海贝；三倍状态下 `+300`。
- 失误、目标逃脱或御守失败：扣分并清空连击，库存最低为 0。

### 主尊训斥 QTE

- 训斥攻击阶段统计敲鼓次数，不采用“按住”判定。
- 攻击窗口统一为 3 秒；亲子 6 次、中间 10 次、狂潮 14 次、极速 12 次，达标才获得御守奖励。

### 贝潮连锁

- 6 秒内连续追回 3 匹铜马会触发额外贝奖励：第一关 +600，第二关 +900。
- 连锁完成会播放三连编钟音，并清空连锁计数。

## 9. 段位

- 10000+：`SSS·古滇御神`
- 6000+：`S·首席守器人`
- 3000+：`B·螺髻驯马师`
- 3000 以下：`D·初醒守器学徒`

结算页同时展示“本局海贝账簿”，分别列出铜马追回、主尊赏赐、铜鼓震虎与器身漏贝的数据。

## 10. 排行榜

- 按操控端分为四榜：键盘榜、手柄榜、鼠标榜、触屏榜，互不影响。
- 每端最多保留 20 条记录，结算展示前 5 名，可用标签切换查看其它端。
- 同一账号在同一端只保留历史最高分；旧版无端信息的记录统一归入键盘榜。
- 游客成绩不进入榜单，结算页会明确提示。

## 11. 新手教程

- 首次登录并选好操控方式后询问一次是否进入教程；跳过也记为“已询问”，不再打扰。
- 五步：认器盖 → 旋盖对准 → 敲鼓封印 → 主尊连打 → 震落双虎。
- 不计时、不扣分、不记榜；`Esc`、手柄 `B` 或「跳过教程」可随时退出。
- 完成后账号记录“教程已完成”，可在账号面板查看，也可以随时点左下角「新手教程」重看。

## 12. 游戏通告

- 左下角「通告」按钮，有未读时显示红点；登录页底部显示最新一条的摘要。
- 通告内容本地维护，已读状态保存在本机。
- 首屏通告用于告知版本变化：账号上线、四端操控、新手教程、铜马重绘。

## 13. 本地数据

- 账号：`gudian_accounts_v2`，最多 24 个。
- 榜单：`gudian_leaderboard_v2`，四端各 20 条。
- 会话：`gudian_session_v2`（记住我）。
- 偏好：`gudian_prefs_v2`（上次操控端、手感、难度）。
- 通告已读：`gudian_notices_read_v2`。
- 旧版 `gudian_last_player`、`gudian_leaderboard` 仅用于首次迁移。

## 14. 必须保持的约束

- 游戏名称严格为《器盖上的复活夜：古滇万贝迷踪》。
- 一局严格 60 秒。
- 支持键盘、HTML5 Gamepad API、鼠标与触摸四类输入。
- 可完全断网运行，账号不联网。
- 所有图片使用仓库内相对路径。
- 铜马必须是图形而非文字圆点，并保留外冲与警示反馈。
- 文物考据内容不得随意虚构或改变。
