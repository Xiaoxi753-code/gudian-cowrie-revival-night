# 《器盖上的复活夜：古滇万贝迷踪》产品规范

## 1. 产品定位

以“驯马场面铜贮贝器”为核心文化原型的 60 秒离线街机游戏。玩家扮演闭馆后的守器人，通过旋转器盖与敲响铜鼓，追回七匹铜马带走的海贝。

产品目标：一分钟内上手、单一动作贯穿全局、强反馈、可重复挑战，并让玩法与器物结构形成明确联系。

## 2. 核心叙事

1. 博物馆闭馆后，器盖上的人马苏醒。
2. 七匹铜马携带海贝沿器盖逃窜。
3. 玩家旋转器盖、敲响中央铜鼓，追回海贝。
4. 御神主尊发出雷霆训斥，玩家敲鼓御守。
5. 黎明前双虎攀器夺贝，玩家连续敲鼓将其震落。
6. 晨光照入展厅，一切重新凝固，成绩写入万贝守器榜。

## 3. 用户流程

```text
四幕故事与计分说明
  → 姓名登记
  → 键盘/手柄模式选择
  → 两键说明
  → 三秒倒数
  → 60 秒游戏
  → 结算、文物考据与本机排行榜
```

## 4. 操作规范

### 键盘模式

- `←` / `→`：旋转器盖、选择目标。
- `空格`：敲鼓；用于封印铜马、抵御训斥、击退双虎。
- `Enter`：确认与开始。
- `Esc`：返回模式选择。

### 手柄模式

- `A` 或 `Start`：推进开场剧情、登记姓名、确认与开始。
- 左摇杆：按 360° 方向自动吸附到最近的铜马槽位，箭头不得停在两个槽位之间。
- 十字键：逐个切换铜马槽位。
- `A`：敲鼓；用于全部核心动作。
- `Y`：结算画面至少展示 5 秒后开启下一局。
- `B`：返回模式选择。

## 5. 一局节奏

- 60～50 秒：七马携贝苏醒，目标停留 3.6 秒。
- 50～40 秒：完成热身，目标停留 3.0 秒。
- 40～20 秒：午夜迷踪，目标停留 2.7 秒。
- 20～0 秒：双虎攀器，目标停留 2.5 秒并增强整体反馈。
- 每 12 秒触发一次主尊训斥。
- 剩余 20 秒时触发一次 3 秒双虎连打。

游戏时间以真实时间计算，事件不会延长一局的 60 秒上限。

## 6. 计分规则

- 普通封印：基础 `+300` 海贝。
- 0.38 秒内完成：基础奖励提高为 `+500` 海贝。
- 连击达到阈值：自动双倍。
- 铜鼓灵力达到 100%：自动进入 5 秒三倍“万贝归潮”。
- 主尊御守成功：`+800` 海贝。
- 双虎阶段每次有效敲鼓：`+100` 海贝；三倍状态下 `+300`。
- 失误、目标逃脱或御守失败：扣分并清空连击，库存最低为 0。

## 7. 段位

- 10000+：`SSS·古滇御神`
- 6000+：`S·首席守器人`
- 3000+：`B·螺髻驯马师`
- 3000 以下：`D·初醒守器学徒`

## 8. 本地数据

- 玩家姓名最多 12 个字符。
- 上一次姓名保存在 `gudian_last_player`。
- 排行榜保存在 `gudian_leaderboard`。
- 最多保留 20 条记录，结算展示前 5 名。
- 所有数据只保存在当前浏览器，不进行网络传输。

## 9. 必须保持的约束

- 游戏名称严格为《器盖上的复活夜：古滇万贝迷踪》。
- 一局严格 60 秒。
- 支持键盘与 HTML5 Gamepad API。
- 可完全断网运行。
- 不依赖鼠标完成游戏流程。
- 所有图片使用仓库内相对路径。
- 文物考据内容不得随意虚构或改变。
