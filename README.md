# 器盖上的复活夜：古滇万贝迷踪

一款围绕“驯马场面铜贮贝器”创作的 60 秒离线街机游戏。玩家扮演闭馆后的守器人，旋转器盖、敲响铜鼓，追回被七匹铜马带走的海贝，并在黎明前抵挡主尊训斥与双虎攀器。

游戏使用 Web Audio 实时合成青铜器低鸣、编钟旋律与事件音效，无需下载音频文件，断网也可完整播放。

受浏览器自动播放规则限制，首次打开页面时需要点击一次画面或按任意键盘键授权声音。右下角显示“声音已开启”后，手柄游玩期间无需再次操作。

## 运行

直接双击根目录的 `index.html`。游戏不依赖网络、服务器、CDN 或安装步骤。

## 操作

### 电脑键盘

- `←` / `→`：旋转器盖、选择铜马
- `空格`：敲响铜鼓
- `Enter`：确认或开始
- `Esc`：从操作说明返回模式选择

### 游戏手柄

- `A` 或 `Start`：推进开场剧情、确认姓名与开始游戏
- 左摇杆：按方向自动吸附到最近的铜马槽位
- 十字键：逐个切换铜马槽位
- `A`：敲响铜鼓
- `Y`：结算画面停留 5 秒后开启下一局
- `B`：从操作说明返回模式选择

## 双关卡难度

- 「亲子启蒙」：面向约 3～6 岁儿童，铜马停留更久、只安排两次训斥、训斥只需 6 次连打，失误不扣贝。
- 「守器初醒」：标准目标时间、四次主尊训斥与标准奖惩，是当前的中间难度。
- 「万贝狂潮」：单个玩家的历史最高分达到 `30,000` 贝后解锁；目标更快、御马更多、五次训斥、失误惩罚提高，但驯马奖励为 `1.5` 倍。
- 雷霆训斥统一为 3 秒攻击窗口，并显示连打进度：亲子 6 次，中间 10 次，狂潮 14 次。
- 手柄的剧情、选择、确认、锁马、连打、击虎和重开按键都会触发短促震动；奖励、惩罚和事件会叠加更强震动。
- 每局结束返回难度选择页，可自由选择已解锁的关卡。

## 开发约定

- 运行时保持零依赖，禁止加入远程 CDN 或远程字体。
- 图片统一放入 `assets/images/`，使用小写 kebab-case 命名。
- `index.html` 是发布产物，也是唯一运行入口；其中按 HTML、CSS、JavaScript 三段组织。
- 修改后运行 `npm run check`。首次使用开发工具时先运行 `npm install`；这不影响游戏本身离线运行。
- 排行榜仅保存在浏览器 `localStorage`，不会上传玩家姓名或成绩；同一姓名只保留一条历史最高分。
- 结算页必须展示本局驯马、御守、震虎与漏贝的海贝账簿。
- 主尊训斥改为 A/空格连打计数：第一关 10 次、第二关 14 次，达标才算御守成功。
- 6 秒内连续追回 3 匹铜马会触发“贝潮连锁”额外奖励。
