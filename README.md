# 器盖上的复活夜：古滇万贝迷踪

一款围绕“驯马场面铜贮贝器”创作的 60 秒离线街机游戏。玩家扮演闭馆后的守器人，旋转器盖、敲响铜鼓，追回被七匹铜马带走的海贝，并在黎明前抵挡主尊训斥与双虎攀器。

游戏使用 Web Audio 实时合成青铜器低鸣、编钟旋律与事件音效，无需下载音频文件，断网也可完整播放。

受浏览器自动播放规则限制，首次打开页面时需要点击一次画面或按任意键盘键授权声音。右下角显示“声音已开启”后，游玩期间无需再次操作。

## 运行

直接双击根目录的 `index.html`。游戏不依赖网络、服务器、CDN 或安装步骤。

手机、平板与触屏电脑同样直接打开即可；竖屏会提示横过来。

## 账号

- 首次进入需要**注册**或从**本机名册**点选已有账号，也可以用「游客试玩」（成绩不记榜）。
- 登录支持 **游戏名** 或 **邮箱**；邮箱在注册时选填。
- 旧版本只用姓名登记，第一次打开新版时会自动把名册里的姓名转成账号，**初始口令统一为 `12345678`**。
- 「记住我」默认勾选，本机下次打开会直接进入名册页。
- 账号、口令与成绩都只保存在当前设备的浏览器里，不上传、不需联网，也不跨设备同步。

## 操作

### 电脑键盘

- `←` / `→`：旋转器盖、选择铜马
- `空格`：敲响铜鼓
- `Enter`：确认或开始
- `Esc`：返回上一层

### 游戏手柄

- `A` 或 `Start`：推进剧情、登录名册、确认与开始
- 左摇杆：按方向自动吸附到最近的铜马槽位
- 十字键：逐个切换铜马槽位
- `A`：敲响铜鼓
- `Y`：结算画面停留 5 秒后开启下一局
- `B`：返回上一层

### 鼠标 / 触屏

点按手感三选一，随时可以在「账号」面板里更换：

- **点马即敲**：点发光的铜马＝旋盖对准＋敲鼓，最快。
- **两步操作**：先点铜马旋盖，再点铜鼓或右下角大鼓。
- **滑动旋盖**：拖动器盖连续旋转，点铜鼓敲击，最像亲手转盖。

三种手感计分完全一致。鼠标点画面即可敲鼓，不需要额外按钮；「敲鼓」大按钮只在触屏需要连打时出现。

## 四档难度

- 「亲子启蒙」：面向约 3～6 岁儿童，铜马停留更久、只安排两次训斥、训斥只需 6 次连打，失误不扣贝。
- 「守器初醒」：标准目标时间、四次主尊训斥与标准奖惩，是当前的中间难度。
- 「万贝狂潮」：账号历史最高分达到 `30,000` 贝后解锁；目标更快、御马更多、五次训斥、失误惩罚提高，但驯马奖励为 `1.5` 倍。
- 「极速试炼」：无需积分解锁；铜马刷新更快，专门挑战反应速度，抓得越快速度倍率越高。

所有关卡都采用“极速猎贝”计分：单匹铜马反应时间低于 0.45 秒得 `×2.2`，低于 0.9 秒得 `×1.7`，低于 1.5 秒得 `×1.3`，其余为 `×1.0`。

- 雷霆训斥统一为 3 秒攻击窗口，并显示连打进度：亲子 6 次，中间 10 次，狂潮 14 次。
- 手柄的剧情、选择、确认、锁马、连打、击虎和重开按键都会触发短促震动；奖励、惩罚和事件会叠加更强震动。
- 每局结束返回难度选择页，可自由选择已解锁的关卡。

## 排行榜

成绩按**操控端**分开排名，四端互不影响：

| 榜单   | 说明                         |
| ------ | ---------------------------- |
| 键盘榜 | 旧版本的历史成绩统一归入此榜 |
| 手柄榜 | 摇杆 / 十字键操作            |
| 鼠标榜 | 鼠标点按操作                 |
| 触屏榜 | 手机、平板、触屏电脑         |

- 每端最多保留 20 条、结算展示前 5 名，同一账号在同一端只保留历史最高分。
- 结算页可以直接点四个标签查看其他端的榜单。

## 新手教程

- 第一次登录（或第一次选完操控方式）会询问是否进入教程，**只问一次**；之后可随时点左下角「新手教程」重看。
- 五步：认器盖 → 旋盖对准 → 敲鼓封印 → 主尊连打 → 震落双虎。
- 教程不计时、不扣分、不记榜，中途可以按 `Esc` 或点「跳过教程」退出。
- 完成后该账号会记录“教程已完成”，账号面板里可以看到状态。

## 游戏通告

左下角「通告」按钮，带未读红点。登录页底部也会显示最新一条。通告本地定义、已读状态存在本机。

## 开发约定

- 运行时保持零依赖，禁止加入远程 CDN 或远程字体。
- 图片统一放入 `assets/images/`，使用小写 kebab-case 命名。
- `index.html` 是发布产物，也是唯一运行入口；其中按 HTML、CSS、JavaScript 三段组织。
- 修改后运行 `npm run check`。首次使用开发工具时先运行 `npm install`；这不影响游戏本身离线运行。
- 玩法逻辑只识别 `LEFT` / `RIGHT` / `A` / `START` / `BACK` 五个统一动作，输入层负责把键盘、手柄、鼠标与触摸映射成动作。
- 铜马使用内联 SVG 剪影，目标亮起时向外围冲刺，缰绳与马圈进入警告状态；不要退回文字圆点。
- 结算页必须展示本局驯马、御守、震虎与漏贝的海贝账簿。
- 主尊训斥使用 A/空格连打计数，达标才算御守成功。
- 6 秒内连续追回 3 匹铜马会触发“贝潮连锁”额外奖励。
